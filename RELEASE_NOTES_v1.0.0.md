# TrafficMonitor v1.0.0 🎉

The first release of **TrafficMonitor** — a tiny, private, real-time network
speed meter for Windows. Live download / upload speed on your desktop or right
on the taskbar. **100% offline**: it only reads the OS network counters and
never makes a connection of its own.

```
↓ 1.2 MB/s
↑ 0.3 MB/s
```

## ✨ Highlights
- ⚡ **Live up/down speed** with selectable refresh (0.5 / 1 / 2 / 5 s)
- 🔔 **System-tray icon** in the notification area (Show/Hide, Settings, Quit)
- 🔤 Uses your **real Windows system font** by default (or pick any font)
- 🎨 **Per-item colors** (background, download ↓, upload ↑, session total)
- 🌗 **Themes** — Auto (light/dark) · Dark · Light · **Transparent**
- 📌 **Reliably on top** — never buried, even when it sits on the taskbar
- 🧲 **Snap** to corners or just left of the system tray
- 🔒 **Lock position** · 🎮 **auto-hide on fullscreen** · 🪟 **start with Windows**
- 📐 **Units**: Auto KB/MB · B/KB/MB · KB/s · MB/s · **Mbps**
- 🛠️ Full **Options dialog** + right-click menu (with ✔ ticks on the current choice)

## 📥 Downloads
- **`TrafficMonitor.exe`** — portable, just run it (no install)
- **`TrafficMonitor-Setup.exe`** — per-user installer (no admin needed)

> ⚠️ Windows SmartScreen may warn on a new unsigned app — click
> **More info → Run anyway**. You can also build it yourself from source, or
> scan it on [VirusTotal](https://www.virustotal.com/).

## 🔐 Privacy
No telemetry, no ads, no accounts, no network connections. Settings live in a
local `config.json` next to the app.
